# Bonsai

Bonsai is an audio recording and mixing application built with [JUCE](https://juce.com).

**Current status (v0.1):** load mono and stereo audio files onto tracks, see their
waveforms, and play / pause / stop them together. Recording from audio devices and
audio processing are planned for later versions.

## Features

- Load WAV, AIFF, FLAC, Ogg Vorbis and MP3 files. Use **Load Audio...**, drag and drop onto the timeline, or pass files on the command line.
- Mono files become mono tracks and stereo files become stereo tracks. Stereo tracks show left and right as separate waveform lanes.
- Files at a different sample rate from the audio device are resampled when they're loaded.
- All tracks play in sync and are mixed to the output.
- Each track has mute and solo buttons. While any track is soloed, only soloed tracks are heard; mute wins over solo. Tracks that won't be heard are greyed out.

| Control | Action |
| --- | --- |
| Space | Play / pause |
| Enter or Home | Return to the start |
| Ctrl+O | Load audio |
| Click a track | Select (highlight) it |
| Speaker icon in a track's header | Mute / unmute the track (a red circle and line means muted) |
| **S** button in a track's header | Solo / unsolo the track (yellow means soloed) |
| Trash-can button, right-click a track > Delete Track, or Delete key | Remove the selected track (asks first; the file on disk is not touched) |
| Click or drag on the ruler or a waveform | Move the playhead |
| Ctrl + mouse wheel | Zoom in / out |
| Shift + mouse wheel | Scroll in time |

## Building

Requirements:
- Visual Studio 2022 with the **Desktop development with C++** workload
- [JUCE 9.0.4](https://github.com/juce-framework/JUCE/releases/tag/9.0.4), placed next to this repo:

```
AudioApps/
  Bonsai/                     <- this repo
  juce-9.0.4-windows/JUCE/    <- JUCE
```

Open **`Bonsai.sln`** in Visual Studio 2022. Pick Debug or Release, then press F5.
The solution has two projects:

- **Bonsai**: the app (the startup project)
- **BonsaiTests**: engine unit tests. Right-click > Set as Startup Project, then run.

Built programs go to `x64\<Configuration>\App\Bonsai.exe` and `x64\<Configuration>\ConsoleApp\BonsaiTests.exe`.

### Adding files or changing project settings

The Visual Studio projects are generated by JUCE's **Projucer** (`juce-9.0.4-windows/JUCE/Projucer.exe`)
from `Bonsai.jucer` (the app) and `Tests/BonsaiTests.jucer` (the tests). To add a source file
or change a setting, open the `.jucer` file in Projucer, make the change, and save. Projucer
then rewrites the project files, and Visual Studio offers to reload them. Changes made only in
Visual Studio's project properties are lost the next time Projucer saves.

Engine source files (`Source/Engine`) are compiled by both projects, so add those to both `.jucer` files.
